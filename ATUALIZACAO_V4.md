# Atualização V4

1. Execute `supabase_update_v4.sql` no SQL Editor do Supabase.
2. Substitua os arquivos do GitHub pelos arquivos desta versão.
3. Aguarde o GitHub Pages atualizar.
4. No Android/Chrome, recarregue a página. O botão Instalar usará o prompt nativo quando o navegador considerar o PWA instalável.
5. No iPhone/iPad, use Compartilhar → Adicionar à Tela de Início.

A V4 inclui os ícones 192x192 e 512x512 derivados do brasão fornecido e adiciona a opção Limpar histórico.
